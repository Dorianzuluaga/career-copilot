Implement Feature 1: Application Workspace exactly as specified.

Requirements

- Frontend only.
- Follow the approved Feature Specification.
- Follow the existing project architecture.

- Authentication

- AI integration
- Backend API
- Prisma
- PostgreSQL
- PDF generation
- ATS analysis
- Any functionality not explicitly defined in the Feature Specification

Important

- Do not make assumptions when requirements are ambiguous.
- If any part of the Feature Specification is unclear or incomplete, stop and explain the ambiguity before implementing.
